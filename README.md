# The Pathological Attractor: A Universal Dissipative Systems Framework for Chronic Disease and Curative Remission

This repository provides an open-source (MIT Licensed) implementation of a unified mathematical framework for chronic pathologies across human physiology, modeling disease as the non-equilibrium stabilization of maladaptive immune-tissue states.

## Theoretical Foundations

1. **The 4-Dimensional Universal Manifold**:
   Across diverse organ systems, chronic disease dynamics are reduced to four canonical state variables:
   - P: Parenchymal somatic density and functional barrier integrity
   - D: Dysfunctional, dedifferentiated, or damaged tissue burden
   - I_cyt: Cytotoxic and effector inflammatory immune activity
   - I_reg: Regulatory, protective, and self-tolerance immune activity

2. **Multidisciplinary Disease Case Studies**:
   - Metabolic System (Type 1 and Type 2 Diabetes Mellitus)
   - Oncological System (Tumor Microenvironment and Cancer Stem Cell Attractors)
   - Exocrine System (Sjogren Syndrome and Autoimmune Glandular Destruction)
   - Epithelial Barrier System (Atopic Dermatitis and Type 2 Pruritic-Barrier Loops)

3. **Curative Remission Principles**:
   - Willems dissipative supply rate conditions and Lyapunov energy barrier crossing
   - Saddle-node separatrix traversal via finite-duration pulsed steering
   - Koopman operator spectral gap softening (Omega_1 -> 0) for pre-symptomatic early warning

## Directory Structure

- `src/universal_disease_dynamics.py`: Universal 4-dimensional non-linear dynamical systems class and disease-specific parameter mappings.
- `simulate_four_diseases_remission.py`: Unified simulation demonstrating bistable attractor capture and pulse-induced autonomous curative remission across all four disease archetypes.
- `simulate_universal_early_warning.py`: Pre-symptomatic Koopman gap softening and Raychaudhuri convergence diagnostics.
- `results/`: Numerical trajectory CSVs and high-resolution phase portraits.
- `The_Pathological_Attractor.tex`: Formal mathematical manuscript.
